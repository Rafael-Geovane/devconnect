1. Preparar o projeto
a) Verificar se o projeto está funcionando // Garante que o Projeto está 
executando corretamente antes do deploy
php artisan serve
2. Criar os arquivos necessários
a) Criar o arquivo “render .yaml” // Arquivo de configuração utilizado pelo 
Render para identificar o tipo de serviço da aplicação
services:
  - type: web
    name: projeto-app
    env: docker
    plan: free
b) Criar o arquivo “Dockerfile” // Arquivo responsável por criar o ambiente 
da aplicação dentro de um container Docker
FROM php:8.3-apache
# Define a imagem base do PHP  8.3 com Apache
RUN apt-get update && apt-get install -y \
    git \
    curl \
    zip \
    unzip \
    libpq-dev \
    libzip-dev \
    && docker-php-ext-install pdo pdo_pgsql zip
# Instala dependências necessárias para Projeto e PostgreSQL
COPY  --from=composer:latest /usr/bin/composer /usr/bin/composer
# Copia o Composer para dentro do container
WORKDIR /var/www/html
# Define a pasta principal da aplicação
COPY  . .
# Copia todos os arquivos do projeto para dentro do container
RUN composer install --no-dev --optimize-autoloader
# Instala as dependências do Projeto em modo produção
RUN cp .env .example .env
# Cria automaticamente o arquivo .env
RUN php artisan key:generate
# Gera automaticamente a APP_KEY  do Projeto
RUN chown -R www-data:www-data /var/www/html/storage
RUN chown -R www-data:www-data /var/www/html/bootstrap/cache
# Define permissões necessárias para cache, logs e sessões
RUN a2enmod rewrite
# Ativa o módulo rewrite do Apache necessário para as rotas do Projeto
COPY  .docker/vhost.conf /etc/apache2/sites-available/000-default.conf
# Copia a configuração personalizada do Apache
EXPOSE 80
# Libera a porta 80 para acesso da aplicação
3. Criar configuração do Apache
a) Criar a pasta “.docker” // Pasta utilizada para armazenar arquivos de 
configuração do Docker e Apache
b) Dentro da pasta criar o arquivo “vhost.conf” // Arquivo responsável por 
configurar o Apache para abrir corretamente a pasta public do Projeto
<VirtualHost *:80>
    DocumentRoot /var/www/html/public
    <Directory /var/www/html/public>
        AllowOverride All
        Require all granted
    </Directory>
</VirtualHost>
4. Criar um repositório no GitHub // O Render utilizará o GitHub para 
baixar e publicar automaticamente o projeto
a) Executar os comandos na pasta raiz do projeto
git init
git add .
git commit -m "Primeiro commit"
git branch -M main
git remote add origin URL_DO_REPOSIT ORIO
git push -u origin main
5. Criar o banco PostgreSQL  no Render // Banco de dados online utilizado 
pela aplicação Projeto
a) No painel do Render clique em:
New +
PostgreSQL
b) Preencher os dados:
Campo Valor
Name projeto-db
Databas
eprojeto
User projeto
c) Clique em:
Create Database
6. Pegar os dados do banco // Informações necessárias para conectar o 
Projeto ao PostgreSQL
a) Após criar o banco o Render mostrará:
Hostname
Port
Database
Username
Password
Internal Database URL
External Database URL
b) Utilizar essas informações no Projeto
DB_CONNECTION=pgsql
DB_HOST=dpg-xxxxx.render .com
DB_POR T=5432
DB_DA TABASE=projeto
DB_USERNAME=projeto_user
DB_P ASSWORD=senha
7. Criar o W eb Service // Serviço responsável por executar a aplicação 
Projeto online
a) Clique em:
New +
b) Escolha:
Web Service
c) Conecte sua conta GitHub // Permite que o Render acesse os 
repositórios
d) Escolha o repositório do projeto Projeto
e) Configure os campos abaixo:
Campo Valor
Language Docker
Branch main
RegionOregon ou 
Virginia
Root 
Directoryvazio
f) Clique em:
Deploy W eb Service
8. Gerar uma APP_KEY  // Chave de criptografia utilizada pelo Projeto para 
segurança da aplicação
a) Na pasta local do projeto execute:
php artisan key:generate --show
b) Copie a chave gerada // Ela será utilizada nas variáveis de ambiente do 
Render
9. Configurar variáveis de ambiente // Configurações principais da 
aplicação Projeto no servidor
a) No painel do serviço acesse:
Environment → Add Environment V ariable
b) Adicione as variáveis abaixo:
APP_NAME=Projeto
APP_ENV=production
APP_KEY={CHA VE_GERADA}
APP_DEBUG=false
APP_URL=https://SEUAPP .onrender .com
LOG_CHANNEL=stack
DB_CONNECTION=pgsql
DB_HOST=
DB_POR T=5432
DB_DA TABASE=
DB_USERNAME=
DB_P ASSWORD=
CACHE_ST ORE=file
QUEUE_CONNECTION=sync
SESSION_DRIVER=file
